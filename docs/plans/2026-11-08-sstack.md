# sstack Implementation Plan

> **For agentic workers:** Execute task by task; steps use checkbox (`- [ ]`) syntax
> for tracking. Read `docs/design.md` first — this plan argues from it.

**Goal:** Build the sstack repo: 12 portable skills, a stdlib-Python dispatcher that
routes roles to harnesses/models from layered TOML, a lessons store, an installer,
and a local sidebar dashboard.

**Architecture:** Skills are plain folders of Markdown. All behaviour that must be
exact lives in four small Python modules under `lib/` (config, dispatch, lessons,
ui server), each exposed by a thin executable in `bin/`. The dashboard is one
static HTML page in `ui/` served by `bin/sstack-ui`, reading and writing the same
files agents use.

**Tech Stack:** Python ≥ 3.11 stdlib only (`tomllib`, `subprocess`, `http.server`,
`unittest`, `concurrent.futures`); plain HTML/CSS/JS; no npm/pip.

**Spec:** `docs/design.md`

## Global Constraints

- Python ≥ 3.11, stdlib only. Tests: `python3 -m unittest discover -s tests -v`.
- No build step, no generated files.
- SKILL.md bodies contain no Claude-only tool names (`Agent(`, `Task(`,
  `AskUserQuestion`, `EnterPlanMode`, `ExitPlanMode`, `TodoWrite`) — those live only
  in `skills/sstack/harness-notes/*.md`.
- SKILL.md length: `sstack` ≤ 200 lines, every other ≤ 150 lines.
- Config paths: `~/.sstack/config.toml` → `<git root>/.sstack/config.toml` →
  `<git root>/.sstack/config.local.toml`.
- Dispatch exit codes: 0 ok + non-empty report; 1 child failed / empty report /
  config refused; 2 timeout; 3 local or unconfigured (prints `local`).
- Implement default: harness `pi`, model `opencode-go/deepseek-v4.1-flash`,
  effort `high`.
- Read-only roles: `scout`, `investigate`, `plan`, `review`.
- Dashboard binds `127.0.0.1` only and requires a token.
- **No git commits until every check in Task 12 passes; then exactly one commit.**
  (User instruction.) Never touch `~/.claude/skills` etc. except through
  `bin/sstack-install`, and run that against a temp HOME in tests.
- `HOME` is always read from `os.environ["HOME"]` (via `Path.home()`), so tests
  isolate by setting `HOME`.

## Review Focus

1. **A config file with a TOML syntax error** → one-line error naming the file and
   line, exit 1, no traceback. (Task 1 test `test_bad_toml_names_file`.)
2. **Running outside a git repo** → dispatch uses cwd as root and only the global
   layer; no crash. (Task 1 test `test_no_git_root_uses_global_only`.)
3. **A child that spawns grandchildren and ignores the timeout** → whole process
   group killed, exit 2 within timeout + 5 s. (Task 2 test
   `test_timeout_kills_process_group`.)
4. **Hand-edited lessons.md with free-form lines** → unknown lines preserved
   byte-for-byte when a lesson is accepted/forgotten. (Task 3 test
   `test_unknown_lines_preserved`.)
5. **Saving a role from the dashboard into a config file that has comments and
   other tables** → only that `[role.X]` table changes; everything else
   byte-identical. (Task 5 test `test_replace_role_table_preserves_rest`.)

## File Structure

```
lib/sstack_config.py     load + merge layers, resolve a role to members
lib/sstack_dispatch.py   build argv, run members, timeouts, runs index, CLI main
lib/sstack_lessons.py    parse/render/add/accept/forget lessons.md, CLI main
lib/sstack_ui.py         HTTP server, JSON API, TOML role-table writer
bin/sstack-dispatch      thin: sys.path += lib; sstack_dispatch.main()
bin/sstack-lessons       thin → sstack_lessons.main()
bin/sstack-ui            thin → sstack_ui.main()
bin/sstack-install       installer (self-contained, stdlib)
bin/sstack-reflect-hook  SessionEnd hook → background reflect pass
ui/index.html            dashboard (from the approved preview)
config.example.toml      global example from design §Routing config
skills/<12 skills>/...   Markdown
tests/test_config.py  tests/test_dispatch.py  tests/test_lessons.py
tests/test_ui.py  tests/test_install.py  tests/test_skills.py
tests/fakes/fake_agent.py  a stand-in harness for tests
```

`tests/fakes/fake_agent.py <mode>` reads stdin and: `echo` → prints
`REPORT\n` + stdin, exit 0; `empty` → prints nothing, exit 0; `fail` → exit 1;
`sleep` → spawns `sleep 60` child and sleeps 60; `touch <file>` → creates the file
(in cwd) and prints a report.

### Task 2: Dispatcher

**Files:**
- Create: `lib/sstack_dispatch.py`, `bin/sstack-dispatch` (chmod +x), `tests/fakes/fake_agent.py`
- Test: `tests/test_dispatch.py`

**Interfaces:**
- Consumes: Task 1 `load`, `resolve`, `git_root`, `READONLY_ROLES`, `ConfigError`.
- Produces:
  - `fill(template: list[str], values: dict[str, str | None]) -> list[str]` —
    substitutes `{name}`; an element whose placeholder value is None is dropped,
    and so is the element before it if that element starts with `-`.
  - `plan_member(cfg: dict, role: str, member: dict, env: Mapping[str,str], title: str) -> dict`
    → `{"transport": "thread"|"headless", "argv": list[str], "notes": list[str]}`.
    Thread only when `transport.mode` is `auto`/`thread`, env has
    `transport.t3.detect`, harness has `t3_provider`, and role is **not** read-only
    (T3 can't enforce read-only → read-only roles always headless; note it).
    `mode="thread"` with T3 unavailable → `ConfigError`. Read-only role on a
    harness without `headless_readonly` → `ConfigError`. Thread with `effort` set →
    note `"effort dropped in T3 thread"`. `{cli}` = env `T3CODE_CLI_PATH` or
    `~/.t3/bin/t3` (expanded).
  - `run_member(argv: list[str], cwd: Path, brief: str, timeout_s: float, report: Path, transport: str) -> int`
    — `Popen(start_new_session=True)`, brief on stdin, stdout → report; on
    timeout `os.killpg(SIGTERM)`, 2 s later `SIGKILL`, return 2; T3 transport exit 2
    → 1; non-zero → 1; empty report → 1; else 0.
  - `report_path(base: Path, member: dict, n_members: int) -> Path` — single
    member: `base`; panel: `base.with_name(f"{base.stem}.{harness}-{slug(model)}{base.suffix}")`, slug = model with non `[A-Za-z0-9.-]` → `-`.
  - `append_run(root: Path, record: dict) -> None` → one JSON line to
    `root/.sstack/runs/index.jsonl` with keys `ts, task, role, harness, model, transport, exit, secs, report`.
  - `main(argv: list[str] | None = None) -> int` — CLI per design:
    `sstack-dispatch <role> --brief F --report F [--title T] [--dry-run]`.
    Local/unconfigured → print `local`, return 3. Config error → message on
    stderr, return 1. Panel: run members in a `ThreadPoolExecutor(max_parallel)`;
    write an index to `--report` listing each member's report path and exit;
    return 0 if any member returned 0, else 1. `--dry-run` prints, per member,
    `<transport>: <shlex.join(argv)>` plus notes, runs nothing, writes nothing.
    Root = `git_root(cwd)` or cwd.

**Files:**
- Create: `lib/sstack_lessons.py`, `bin/sstack-lessons`

**Interfaces:**
- Produces:
  - `@dataclass Lesson: id: str; status: str; seen: int; text: str; fields: dict[str,str]`
    (`status` ∈ `pending|accepted|encoded`; `fields` holds `evidence`, `encoded`, …)
  - Line grammar: `- [<status>] seen=<n> id=<id> | <text>[ | <key>: <value>]*`
  - `parse(text: str) -> list[Lesson | str]` (non-matching lines kept as str)

    (case/space-insensitive) → `seen += 1`, evidence appended with `; `; else new
    `pending` with next `L<n>` id. Creates file with header `# Lessons\n\n`.
  - `set_status(path: Path, lesson_id: str, status: str, encoded: str | None = None) -> Lesson`
  - `forget(path: Path, lesson_id: str) -> None`
  - `accepted(path: Path) -> list[Lesson]`
  - `main(argv) -> int`: `sstack-lessons add --scope repo|global "text" [--evidence E]` (prints `L<n> seen=<n>`; prints `ENCODE` on a second line when `seen >= reflect.encode_at`), `list [--status S]`, `accept ID --scope S`, `forget ID --scope S`, `encode ID --scope S --target T`.
